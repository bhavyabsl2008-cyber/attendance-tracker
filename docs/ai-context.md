# Project

Name: Presynce

Type:
Attendance intelligence platform for students.

Mission:

Help students understand, predict and improve attendance through intelligent insights instead of raw percentages.

---

# Vision

Presynce should feel like:

- Apple Health for attendance
- Linear for academics
- Notion for organization

Simple.

Fast.

Calm.

Professional.

---

# Core Philosophy

Attendance isn't the product.

Confidence is.

Every feature must reduce uncertainty.

Every number should answer:

"So what?"

---

# Design Principles

Minimal before beautiful.

Information before decoration.

Whitespace over visual effects.

One primary action per screen.

Motion should guide attention, never distract.

---

# Visual Language

No gradients.

No glassmorphism.

No neumorphism.

No gaming aesthetics.

No oversized illustrations.

Use neutral colors.

Accent colors only for important actions.

# Engineering Rules

Business logic should never live inside UI.

Avoid duplicated logic.

Use reusable components.

Keep functions small.

Write readable code first.

---

# Never Do

Never hardcode attendance calculations.

Never duplicate business logic.

Never ignore documentation.

Never create conflicting design systems.
