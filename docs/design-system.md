# Design System

## Design Philosophy

Presynce is calm, precise, and trustworthy.

It should never feel loud, playful, or overwhelming.

The UI should communicate confidence through clarity rather than decoration.

---

# Core Principles

- Information first
- Minimal by default
- Consistent spacing
- Strong typography
- High readability
- Fast interactions

---

# Visual Identity

Keywords:

- Calm
- Professional
- Modern
- Academic
- Data-focused
- Premium

Avoid:

- Gaming aesthetics
- Bright neon colors
- Excessive animations
- Heavy gradients
- Glassmorphism
- Neumorphism

---

# Color Philosophy

Use neutral surfaces.

Accent colors should indicate actions, not decorate the interface.

Status colors should communicate state without causing anxiety.

Danger is reserved for destructive actions.

Low attendance is not an error.

---

# Typography

Display

- Manrope

Body

- IBM Plex Sans

Numbers

- IBM Plex Mono

Numbers should always feel different from normal text.

---

# Layout

Prefer whitespace over borders.

Large sections should breathe.

Cards should group related information.

Every screen should have one obvious primary action.

---

# Components

Primary Button

Used for the single most important action.

Secondary Button

Used for alternative actions.

Cards

Contain one logical group of information.

Runway Bar

Primary attendance visualization.

Never use circular progress indicators.

Attendance behaves like a runway, not a percentage wheel.

---

# Motion

Animations should be quick.

Motion should explain changes.

Avoid decorative animations.

Prefer fades and subtle movement.

---

# Accessibility

Maintain high contrast.

Keyboard navigation should work everywhere.

Never rely solely on color to communicate information.

Touch targets should remain comfortable on mobile.
